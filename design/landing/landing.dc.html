THE CLI

Twelve commands. Every agent speaks them.

Agents write to Linear only through Armada, so every claim, report and question lands in the same format. When a command cannot go on, it prints the reason and the next command to run.

Your keys stay in Armada. Not on laptops, not in prompts.

Enter the Linear key once. Terminals sign in, workers get a one-time token, and Armada hands each command only what it needs.

1 hour A launch token covers one ticket, works once, and expires after an hour. The full brief only ever shows it masked.
