Armada private beta — candidate checklist (publish only after coordinator validates the build)

This build opens directly on Sandboxes; there is no Orchestrators tab, create form,
conversation or details screen. Check this after both a clean install and upgrading
an earlier signed-in build. Existing server orchestrators are not stopped or deleted.

Check email sign-in, session restore/refresh, organization selection/switching and
sign-out. Upgrading preserves the existing session and selected organization; any
old saved orchestrator commands must not be replayed. The older published app must
still work against the unchanged server until this build is published.

Check New Sandbox (+): choose a golden, agent, model, effort and model account;
repository, machine size and lifetime remain under More Options. Launch with a
prompt and confirm the first turn appears. Refused launches keep the fields and
explain why. An unconfirmed launch must not retry automatically.

Check sandbox list grouping, newest-first order, stopped-section collapse, refresh
and next-page loading. Another member's metadata remains visible as allowed, but a
row without access cannot open its private conversation.

Open a sandbox conversation: latest messages appear, history loads on scroll-up
without jumping, streaming text/tool results update, and returning to a recently
opened conversation shows the cached view. Switching organization or signing out
clears that cache. Send a prompt, wait for completion and send a follow-up; the
composer follows the turn status. Stop asks for confirmation and keeps history.
Sending to a stopped sandbox resumes it. Offline/unconfirmed prompts must not be
resent automatically; check the transcript before sending again.

Check iPhone and iPad, light/dark appearance, loading/empty/permission-denied/offline
states, keyboard/composer layout, large text and VoiceOver labels. No simulator or
device run was available during implementation; the coordinator performs these checks.

Report version/build, device/iOS version, steps, expected and actual results. Never
include credentials, verification codes or private conversation data.
